# Fundamentos-da-engenharia

Nesta disciplina, aprendemos conceitos básicos de Engenharia, Ciência, Química e Expressão Gráfica, além de revisarmos conteúdos importantes de Física. Esses conhecimentos ajudaram a desenvolver o raciocínio lógico e a construir uma base teórica necessária para compreender melhor os fundamentos da Engenharia e suas aplicações.
